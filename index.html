Wie ben ik?

Mijn naam is Sebri Ahmed. Ik ben Software Development student en ik werk aan portfolio-projecten waarin frontend, backend en interactie samenkomen. Ik vind het belangrijk dat een website niet alleen werkt, maar ook logisch aanvoelt voor de gebruiker.

In mijn projecten gebruik ik onder andere HTML, CSS, Bootstrap, JavaScript, PHP en MySQL. Daarnaast oefen ik met Git en GitHub, zodat mijn werk overzichtelijk blijft en goed te volgen is.
